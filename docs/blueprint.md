# **App Name**: iSynera AI Solutions

## Core Features:

- Landing Page: Home page showcasing iSynera's services and mission using modern web design.
- Company Information: About Us page that contains a robot representing iSynera.
- AI Assistant: AI-powered chatbot that uses LangChain and Gemini AI to answer user queries by retrieving information from the website content; employs a RAG tool.
- Website Pages: Informational pages for Services, About, Contact, and Get Started sections.

## Style Guidelines:

- Primary color: Saturated blue (#3498db) to evoke trust and innovation. Blue is often used to imply trust and serenity, so it is apt for this kind of solution.
- Background color: Light, desaturated blue (#e7f5ff) to maintain a clean, professional look. Given a lighter styling to communicate professionalism, we need a lighter color scheme as well.
- Accent color: Analogous, brighter cyan (#45b6fe) for interactive elements and calls to action. The hue is close to that of the primary color, creating harmony, but is differentiated with more brightness and saturation so it stands out more.
- Clean, sans-serif font for body text to ensure readability and modernity.
- Sleek, minimalist icons to represent different AI services.
- Use of white space to create a clean, uncluttered design. Use whitespace to organize content with effective chunking, making the UI scannable for users. Users need to feel that your design 'has room to breathe'.
